# 클로드 캡처 도우미 (윈도우용)

화면의 정해 둔 영역을 **키 하나(F8)로 캡처해서 AI 대화창에 바로 붙여 넣는** 프로그램이에요.
클로드, 챗GPT, 제미나이 같은 대화창에 화면을 보여 주며 물어볼 때 편해요.

| 키 | 하는 일 |
|---|---|
| **F7** | 캡처할 영역을 마우스로 드래그해서 정하기 (한 번 정하면 기억해요) |
| **F8** | 캡처 → 사진 폴더에 저장 → 마지막으로 클릭한 대화창에 붙여 넣기 |
| **F9** | 붙여 넣을 대화창 직접 지정하기 (누른 뒤 글 쓰는 칸을 한 번 클릭) |

붙여 넣은 뒤 **설명을 쓰고 엔터**만 누르면 돼요.

---

## 가장 쉬운 방법: 실행파일 받기 (파이썬 필요 없음)

1. 아래 주소를 누르면 **ClaudeCapture.exe** 가 바로 내려받아져요.
   👉 https://github.com/andaya7777-byte/claude-capture/releases/latest/download/ClaudeCapture.exe
2. 내려받은 파일을 **문서** 폴더처럼 지우지 않을 곳에 옮겨 두세요. (F7 로 정한 영역이 이 파일 옆에 저장돼요)
3. 더블클릭하면 켜져요.
   - 파란 **"Windows의 PC 보호"** 창이 뜨면 **추가 정보** → **실행** 을 누르세요. 처음 보는 프로그램이라 뜨는 거예요.
4. 바탕화면 아이콘이 필요하면: 파일을 오른쪽 클릭 → **보내기** → **바탕 화면에 바로 가기 만들기** 를 누르세요.

이렇게 받았다면 아래 "처음 한 번만 하는 준비"는 건너뛰고 **"매일 쓰는 방법"** 으로 가세요.

---

## 처음 한 번만 하는 준비 (파이썬으로 쓰는 방법)

### 1. 프로그램 내려받기
1. 이 페이지 위쪽의 초록색 **`<> Code`** 버튼을 누르세요.
2. 맨 아래 **Download ZIP** 을 누르세요.
3. 내려받은 ZIP 파일을 오른쪽 클릭 → **압축 풀기** 를 누르세요.
4. 압축을 푼 폴더를 **문서** 폴더처럼 지우지 않을 곳에 옮겨 두세요.

### 2. 파이썬 설치하기 (이미 깔려 있으면 건너뛰세요)
1. 인터넷에서 **python.org** 에 들어가 노란 **Download Python** 버튼을 눌러 받으세요.
2. 받은 파일을 실행하면 첫 화면 아래쪽에 **Add python.exe to PATH** 칸이 있어요.
   **꼭 체크하고** **Install Now** 를 누르세요.

### 3. 부품 설치하기
- 폴더 안의 **install.bat** 을 더블클릭하세요.
- 까만 창에 글자가 쭉 올라가다가 **DONE** 이 나오면 아무 키나 누르세요.

### 4. 바탕화면 아이콘 만들기
- 폴더 안의 **make_shortcut.bat** 을 더블클릭하세요.
- 바탕화면에 주황색 **"클로드 캡처"** 아이콘이 생겨요.

---

## 매일 쓰는 방법

1. 바탕화면의 **클로드 캡처** 아이콘을 더블클릭하세요.
   화면 오른쪽 아래(시계 옆 `^` 안)에 주황색 동그라미 아이콘이 생기면 켜진 거예요.
2. 처음이면 **F7** 을 누르고 캡처할 영역을 드래그하세요.
3. 대화창(클로드, 챗GPT, 제미나이 등)의 **글 쓰는 칸을 한 번 클릭**해 두세요.
4. 작업하다가 **F8** 을 누르면 캡처한 그림이 그 대화창에 들어가요.

### 자동으로 찾아가는 대화창
F9 로 지정하지 않아도 아래 대화창은 마지막으로 클릭한 곳을 알아서 찾아가요.

- 인터넷 창(크롬, 엣지, 웨일 등)에서 쓰는 것: 챗GPT, 제미나이, 클로드, 코파일럿, 퍼플렉시티, 그록, 딥시크, 젠스파크, 뤼튼, 클로바X, 노트북LM
- 컴퓨터에 깔아서 쓰는 앱: 데스크톱 클로드, VS Code, ChatGPT 앱, 퍼플렉시티 앱, 커서

이 목록에 없는 프로그램(예: 카카오톡)은 **F9** 를 누르고 글 쓰는 칸을 한 번 클릭해 지정하세요.
지정은 프로그램을 켤 때마다 한 번씩 해 주세요.

## 알아 두면 좋은 것

- 캡처한 그림은 **사진(Pictures) → 클로드캡처** 폴더에도 저장돼요.
- 주황 아이콘을 오른쪽 클릭하면 메뉴가 나와요: 캡처 / 영역 다시 지정 / 대화창 지정 / 저장 폴더 열기 / 끝내기
- 그림이 대화창에 안 들어가면 글 쓰는 칸을 클릭하고 **Ctrl + V** 하세요. 그림은 이미 복사돼 있어요.
- F7, F8, F9 는 이 프로그램이 켜져 있는 동안 캡처 전용 키가 돼요.
- 대화창 프로그램을 **관리자 권한**으로 켜 두었다면, 이 프로그램도 관리자 권한으로 켜야 자동 붙여 넣기가 돼요.
